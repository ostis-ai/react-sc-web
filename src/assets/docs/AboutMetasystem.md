Метасистема OSTIS — это интеллектуальная компьютерная система, предназначенная для комплексной поддержки всех этапов жизненного цикла интеллектуальных систем, известных как ostis-системы, которые разрабатываются с использованием Технологии OSTIS. Она служит одновременно системой управления проектами и порталом знаний для проектирования, производства, эксплуатации и развития семантически совместимых гибридных интеллектуальных систем.

Метасистема OSTIS обеспечивает:
- комплексную информационную поддержку всех этапов жизненного цикла ostis-систем;
- поддержку совместимости ostis-систем в рамках Экосистемы OSTIS;
- автоматизацию проектирования всех компонентов интеллектуальных компьютерных систем нового поколения;
- комплексную автоматизацию всех этапов жизненного цикла интеллектуальных компьютерных систем нового поколения.

Основой базы Метасистемы OSTIS служит Стандарт Технологии OSTIS, который представляет собой документацию Технологии OSTIS.
