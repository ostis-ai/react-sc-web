Данный раздел содержит инструкции по сборке и разработке ключевых компонентов Технологии OSTIS.
Ниже будет приведен их краткий обзор.

# **Репозитории, входящие в OSTIS AI**

## [ostis-standard](https://github.com/ostis-ai/ostis-standard)
Представляет собой документацию технологии OSTIS, оформленную в виде исходного текста Базы знаний Метасистемы OSTIS.

Для представления знаний используется `SC-код` - универсальный язык представления знаний.

Так, исходный текст стандарта разрабатывается при помощи набора команд языка LaTex, специально разработанных для оформления научных результатов в виде формальных текстов баз знаний однако данный репозиторий также содержит результат его трансляции в строковый вариант `SC-кода` (`SCs-код`), пригодный для погружения в базу знаний.

**Связанные репозитории:**
- Плагин LaTeX для представления знаний в коде SCn: [scn-latex-plugin](#scn-latex-plugin);
- Для трансляции исходников в SCs-код используется [tex2scs-translator](#tex2scs-translator).

<a id="sc-machine"></a>
## [sc-machine](https://github.com/ostis-ai/sc-machine)
Sc-machine является эмулятором семантического компьютера, обеспечивающего хранение и обработку семантических сетей. Для обработки применяется агентно-ориентированный подход.

Включает в себя реализацию sc-сервера, обеспечивающего возможность работы с памятью извне.

<a id="tex2scs-translator"></a>
## [tex2scs-translator](https://github.com/ostis-ai/tex2scs-translator)

tex2scs-translator представляет собой инструмент для трансляции `*.tex` фалов в sc.n-представлении в `*.scs` файлы.

<a id="ostis-metasystem"></a>
## [ostis-metasystem](https://github.com/ostis-ai/ostis-metasystem)

Данный репозиторий является хранилищем Метасистемы Технологии OSTIS.

Метасистема OSTIS — это интеллектуальная компьютерная система, разработанная для обеспечения комплексной поддержки всех этапов жизненного цикла интеллектуальных систем, известных как ostis-систем. Она служит как системой управления проектами, так и порталом знаний для проектирования, производства, эксплуатации и развития семантически совместимых гибридных интеллектуальных систем.

**Связанные репозитории:**
- Требует [sc-mahcine](#sc-machine) в качестве бекенда;
- Исползует [sc-web](https://github.com/ostis-ai/sc-web) и [react-sc-web](https://github.com/ostis-ai/react-sc-web) в качестве интерфейса;
- Имеет в совем составе py-часть, использующую [py-sc-kpm](#py-sc-kpm) и [py-sc-client](#py-sc-client);
- Использует протранслированный в `.scs` [ostis-standard](https://github.com/ostis-ai/ostis-standard) в качестве базы знаний;
- Также использует [sc-component-manager](#sc-component-manager) и [scp-machine](#scp-machine).

<a id="sc-web"></a>
## [sc-web](https://github.com/ostis-ai/sc-web)
Sc-web явяется пользовательским интерфейсом ostis-систем. Долгосрочная идея проекта - создание универсального механизма рендеринга интерфейсов по их описанию в базе знаний.

**Связанные репозитории:**
- Требует [sc-machine](#sc-machine) в качестве бекенда.

<a id="react-sc-web"></a>
## [react-sc-web](https://github.com/ostis-ai/react-sc-web)
React-реализация [sc-web](#sc-web).

**Связанные репозитории:**
- Имеет зависимость от одной из веток [sc-web](#sc-web) для работы с SCg;
- Использует компоненты из [ostis-ui-lib](#ostis-ui-lib);
- Требует [sc-mahcine](#sc-machine) в качестве бекенда.

<a id="ostis-ps-lib"></a>
## [ostis-ps-lib](https://github.com/ostis-ai/ostis-ps-lib)

Этот репозиторий представляет собой централизованное хранилище для компонентов базы знаний и решателя задач для ostis-систем.

Представляет собой набор повторно используемых компонентов и библиотек. Репозиторий организован в несколько модулей, каждый из которых имеет свой собственный набор функций и обязанностей.

**Связанные репозитории:**
- Компоненты направлены на работу с семантической памятью и, следовательно, имеют зависимость от [sc-mahcine](#sc-machine).
- Менеджер компонентов: [sc-component-manager](#sc-component-manager)

<a id="ostis-ui-lib"></a>
## [ostis-ui-lib](https://github.com/ostis-ai/ostis-ui-lib)

Хранилище многократно используемых компонентов интерфейса, аналогичное [ostis-ps-lib](#ostis-ps-lib).

**Связанные репозитории:**
- Компоненты направлены на работу с семантической памятью посредством соответствующего клиента и, следовательно, имеют зависимость от [ts-sc-client](#ts-sc-client) и [sc-mahcine](#sc-machine);
- Менеджер компонентов: [sc-component-manager](#sc-component-manager).

<a id="sc-component-manager"></a>
## [sc-component-manager](https://github.com/ostis-ai/sc-component-manager)

Репозиторий менеджера пакетов в рамках технологии OSTIS.

sc-component-manager позволяет ostis-системам устанавливать повторно используемые компоненты для интеллектуальных систем, созданных с использованием технологии OSTIS. sc-component-manager — это расширение sc-machine.

> В случае платформенно-зависимых компонентов в настоящее время менеджер обеспечивает только скачивание, интеграция их в систему остается в зоне ответственности разработчика.

**Связанные репозитории:**
- Репозиторий компонентов баз знаний и решателей задач: [ostis-ps-lib](#ostis-ps-lib)
- Репозиторий компонентов интерфейса [ostis-ui-lib](#ostis-ui-lib).
- Требует [sc-mahcine](#sc-machine) для работы.

<a id="scl-machine"></a>
## [scl-machine](https://github.com/ostis-ai/scl-machine)

Репозиторий scl-machine — модуля логического вывода, разработанного для технологии OSTIS.

**Связанные репозитории:**
- Требует [sc-mahcine](#sc-machine) для работы.

<a id="ostis-web-platform"></a>
## [ostis-web-platform](https://github.com/ostis-ai/ostis-web-platform)

Репозиторий, содержащий набор скриптов и конфигураций, служащих основой для развертывания существующих и создания новых систем ostis.

> **Устарел**. Не используется начиная с [sc-mahcine](#sc-machine) версии 0.10.0

**Связанные репозитории:**
- Установка включает в себя: [sc-mahcine](#sc-machine), [ims.ostis.kb](#ims-ostis-kb), [sc-component-manager](#sc-component-manager), [scp-machine](#scp-machine) и [sc-web](#sc-web).

<a id="ims-ostis-kb"></a>
## [ims.ostis.kb](https://github.com/ostis-ai/ims.ostis.kb)

Репозиторий содержащий старую версию базы знаний Метасистемы OSTIS. Идейным продолжением его является [стандарт ostis](#ostis-standard).

> **Устарел**. В настоящее время не развивается.

<a id="scp-machine"></a>
## [scp-machine](https://github.com/ostis-ai/scp-machine)

Репозиторий scp-машины — интерпретатора программ на базовом языке программирования технологии OSTIS. В качестве такого языка выступает SCP, программы на котором представляются также в графовом виде.

**Связанные репозитории:**
- scp-machine является расширением [sc-machine](#sc-machine).

<a id="ts-sc-client"></a>
## [ts-sc-client](https://github.com/ostis-ai/ts-sc-client)

Typescript реализация клиента для связи с sc-сервером посредством Websocket.

**Связанные репозитории:**
- sc-сервер является частью [sc-machine](#sc-machine).

<a id="py-sc-client"></a>
## [py-sc-client](https://github.com/ostis-ai/py-sc-client)

Python реализация клиента для связи с sc-сервером посредством Websocket.

**Связанные репозитории:**
- sc-сервер является частью [sc-machine](#sc-machine).

<a id="py-sc-kpm"></a>
## [py-sc-kpm](https://github.com/ostis-ai/py-sc-kpm)

Реализация машины обработки знаний (knowledge processing machine, kpm) на Python - библиотеки предоставляющей инструменты для взаимодействия с базами знаний.

**Связанные репозитории:**
- для взаимодействия с сервером используется [py-sc-client](#py-sc-client).

<a id="scn-latex-plugin"></a>
## [scn-latex-plugin](https://github.com/ostis-ai/scn-latex-plugin)

Этот репозиторий содержит плагин LaTeX для представления знаний в коде SCn.

<a id="kbe"></a>
## [kbe](https://github.com/ostis-ai/kbe)

Редактор исходных текстов баз знаний. Обеспечивает редактирование SCg текстов и их сохранение в пригодный для сборки в базу знаний формат (`.gwf`).

> В настоящее время не развивается, в конечном счете будет заменен на редактор, входящий в состав [sc-web](https://github.com/ostis-ai/sc-web) и [react-sc-web](https://github.com/ostis-ai/react-sc-web).
